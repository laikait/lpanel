# MaxMind test databases

Copied unchanged from MaxMind's own test data,
https://github.com/maxmind/MaxMind-DB/tree/main/test-data (commit
0eef25a), dual-licensed Apache-2.0 / MIT by MaxMind, Inc.

They hold made-up records for a handful of documentation addresses, such as
81.2.69.160 (GB) and 2001:218::1 (JP), so the MaxMind resolver is tested
against real database files without shipping a real GeoIP database.
